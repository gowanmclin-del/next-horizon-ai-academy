# Phase 22 Deployment

1. Copy the Phase 22 update bundle contents into the existing local `next-horizon-ai-academy-phase21` Git repository, allowing folders to merge and files to replace.
2. In GitHub Desktop, review the changed files and commit with: `Phase 22 corporate partnerships and workforce pathways`.
3. Push origin. Railway will build and deploy automatically.
4. In the production Supabase `Website` project, run `supabase/phase22.sql` exactly once.
5. Test `/corporate-partnerships/inquiry`, then verify the submission at `/admin/partnerships`.

Do not delete or recreate the Railway service, domain, environment variables, Supabase project, or GitHub repository.
